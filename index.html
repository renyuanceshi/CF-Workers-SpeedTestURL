核心功能

⚡

一键部署

无需复杂配置，直接克隆仓库并在 Cloudflare 中部署，即可拥有自己的测速地址。

🔧

灵活配置

支持自定义测速大小，通过 URL 路径指定 K/M/G 单位，满足各种测速需求。

🌍

全球加速

基于 Cloudflare CDN，享受全球节点加速，提供稳定的网速测试体验。

🔐

HTTPS 支持

自动支持 HTTP/HTTPS 双协议，确保测速过程安全可靠。

📊

默认 200MB

未指定大小时默认 200MB 测速，适合大多数场景快速评估。

🚀

轻量高效

代码精简，性能卓越，极低的资源占用，高效的数据传输。

快速开始

1

Fork 项目

将项目 Fork 到你的 GitHub 账户

2

创建 Worker

在 Cloudflare 中创建新的 Worker 项目

3

复制代码

将 worker.js 代码复制到 Worker 中

4

部署完成

部署并开始使用你的专属测速地址

使用示例

$ # 默认 200MB 测速 $ curl https://speedtest.example.com $ # 自定义 500MB $ curl https://speedtest.example.com/500m $ # 自定义 1GB $ curl https://speedtest.example.com/1g

准备好了吗？

现在就部署你的 Cloudflare SpeedTest 测速地址
