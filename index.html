v1.3
2024 年 3 月 17 日
Feature
Worker.js 文件标准化： 将 worker.js 重命名为 _worker.js，以符合 Cloudflare Workers 最新部署规范。这使得项目能够更好地支持新版本的 Cloudflare CLI 和自动化部署流程。
v1.2
2024 年 2 月 28 日
Documentation Improvement
README 文档完善： 增强了项目文档的清晰度和可读性。详细说明了默认测速大小、自定义测速参数、使用指南和注意事项，帮助用户快速上手。
v1.0
2024 年 2 月 28 日
Initial Release
项目初始版本发布： 实现 Cloudflare Workers 基础测速功能。支持 200MB 默认测速、自定义测速大小 (K/M/G 单位)、HTTP/HTTPS 双协议，为用户提供完整的云端测速解决方案。
