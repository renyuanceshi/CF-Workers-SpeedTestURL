## 🚀 部署指南

### 方案 1：使用 GitHub Pages（推荐）

1. 在仓库设置中启用 GitHub Pages
2. 选择 `website` 分支作为源
3. 官网将自动部署到 `https://renyuanceshi.github.io/CF-Workers-SpeedTestURL/`

### 方案 2：使用 Cloudflare Pages

1. 连接 GitHub 仓库
2. 选择 `website` 分支
3. 构建命令留空
4. 发布目录设置为 `/`

### 方案 3：自定义域名部署

1. 购买域名
2. 配置 DNS 解析
3. 在 Cloudflare 中启用 Pages
4. 设置自定义域名

## 🔧 自定义修改

### 修改项目名称

编辑 `index.html`：

```html
<!-- 修改导航栏 -->
<div class="logo">⚡ SpeedTest</div>

<!-- 修改页面标题 -->
<title>CF-Workers-SpeedTest | 云端测速解决方案</title>
```

### 修改统计数据

```html
<div class="stat-card">
    <div class="stat-number">XXX</div>
    <div class="stat-label">你的标签</div>
</div>
```

### 修改功能列表

```html
<div class="feature-card">
    <div class="feature-icon">🎯</div>
    <h3>功能标题</h3>
    <p>功能描述...</p>
</div>
```

### 修改颜色主题

编辑 CSS 变量：

```css
:root {
    --primary: #0066ff;           /* 修改主色 */
    --secondary: #ff6b35;         /* 修改辅助色 */
    --success: #10b981;           /* 修改成功色 */
}
```
